# Badge

Etiqueta corta de estado o categoría con tono semántico.

`tone`: `neutral`, `signal` (info, datos), `pulse` (en vivo; con `live` el punto late), `synapse` (IA), `success`, `warning`, `danger`. `dot` añade indicador. Texto de 1–2 palabras en sentence case; el color nunca es el único portador del significado.
