# Card

Contenedor de una idea: eyebrow, título, descripción y contenido.

El consumidor pasa `eyebrow`, `title`, `description` y `children`. `variant`: `default` (`bg-raised` + `border-default` + `shadow-1`), `glass` (sobre imagen o gradiente), `signal` (hairline superior en `gradient-signal`: una por grupo). `interactive` o `href` añaden hover (sube 2 px, `shadow-2`).

- Padding `space-6`, radio `radius-lg`. Una idea por card; título ≤ 5 palabras.
