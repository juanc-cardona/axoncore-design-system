# Assets

- `logo/svg/` — maestros vectoriales: `axoncore-{horizontal|vertical|isotype}-{positive|negative|mono-black|mono-white}.svg`, generados desde el vector oficial. Horizontal = isotipo a la izquierda del logotipo en una línea (isotipo 1,6X, separación 0,75X); vertical = isotipo sobre el logotipo. Tinta fija (sin currentColor): positive/mono-black sobre claro, negative/mono-white sobre oscuro.
- `logo/png/` — pool oficial en PNG (2026-11-10). `Horizontal` = isotipo a la izquierda del logotipo (2074 × 1000 px), `Vertical` = isotipo sobre el logotipo, `Icon` = isotipo (1000 px). `Wbg` = fondo transparente, `bg` = fondo negro. Úsalo solo donde no se admita SVG.
- `favicon/` — `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png` (180), `icon-192.png`, `icon-512.png`, `axoncore-app-icon.svg`.
- `pattern/` — patrón Axon en blanco y negro (tile de 96 px).
